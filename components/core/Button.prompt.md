The action button — use `primary` for the single hero CTA in a panel (violet gradient, full width in the exchange panel), `secondary` for toolbar actions, `ghost` for low-emphasis links like "See all".

```jsx
<Button variant="primary" size="lg" fullWidth trailingIcon="chevron-right">Buy ETH</Button>
<Button variant="secondary" icon="filter">Filters</Button>
<Button variant="ghost" trailingIcon="chevron-right">See all</Button>
```

Sizes: sm 30px, md 38px, lg 44px. Never place two primary buttons side by side.
